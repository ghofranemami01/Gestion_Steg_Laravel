MySQL (Base de données)
Vue.js (Interface utilisateur)
Eloquent ORM

Création d’une API RESTful pour la gestion des abonnés
Opérations CRUD (Create, Read, Update, Delete)
Migration et seeding de la base de données
Affichage de la liste des abonnés via Vue.js
Ajout et modification des abonnés via des vues dédiées
